# چک‌لیست انتشار

- کنترل نهایی لوگوی رسمی در Header و Footer
- جایگزینی تصاویر نمونه با عکس‌های رسمی و رضایت‌نامه تجاری
- تأیید نهایی متن Privacy، Terms و Shipping/Returns
- اتصال OTP، پرداخت، سفارش، موجودی و تخفیف به سرور
- فعال‌سازی HTTPS، CSP، HSTS، CSRF و Secure Cookie
- قراردادن Admin پشت Authentication و RBAC
- تنظیم دامنه Canonical، Open Graph، Sitemap و Robots
- تکمیل شماره تماس، ایمیل، نشانی، شبکه‌ها و نماد اعتماد
- افزودن Analytics با Consent و حداقل Script ثالث
- تست Playwright روی Chrome Android، Safari iOS و Desktop
- تست دسترس‌پذیری با صفحه‌کلید، VoiceOver و TalkBack
- اجرای Lighthouse و RUM روی اینترنت موبایل ایران
- Minify، Brotli، Cache Hash و CDN تصاویر
- تهیه Backup و Rollback Plan برای انتشار
